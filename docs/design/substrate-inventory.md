**Status:** read-only inventory for the owner, 2026-09-14, branch `experiment/point-and-line` @ `d06708d`.
**The criterion (owner):** the reading model is `Point<TSpace>` + read extension methods constrained on the
space's capability interface; a file scopes to an interface; "anything stopping extending Point based on
space has to be remedied." Every row below is judged *enables / neutral / obstructs* against that.

(`git log --follow --diff-filter=A`). "pub" = `grep -c "public "`. **STC** = the self-typed slicing
contract (`ICells` / `ISpace<TSelf>` / `ISpace : ISpace<ISpace>` / `ISheetCells : ISpace, ISpace<ISheetCells>`),
prototyped by the orchestrator on netstandard2.0 the same day.

## What the library is carrying — the short list

1. **The last 10 days added ~2,000 LOC with no consumer outside itself**: the placement pipeline (`PlacementStage`+`.Scoped` = 997 LOC, 2026-09-10) and the analyzers (1,025 LOC, 2026-09-10). Both are the newest and least settled; both are `freeze`.
2. **`Unrect` speaks `CellValue` in 42 public signatures** — 36 view accessors, 4 predicate factories (`Cell`, `RowWithCell`, `RowsWhileAny`, `ColumnsWhileAny`), 2 exploratory rungs. That number *is* the strict-shape work item.
3. **Five `Table` rungs, three still leaf-implemented**; the binder (1,005 LOC) is the single largest reason `CellValue` cannot leave Core.
4. **Two of the four largest subsystems are backends** — streaming 2,647, benchmarks 2,363 — and neither obstructs. The sprawl is in `Unrect`, not around it.
5. **Spec rev 3 has two factual slips**: `ProjectionBase<T>` is public (only its ctor is closed, and IVT would open it — verified), and the views host 36 accessors, not 24.
6. **Spec rev 3 has one real gap**: UNR001 breaks on view reads (T2-3), ~20 lines to fix, needed whichever contract wins.
7. **STC is the better end state.** The agent recommends sequencing it after Point; the orchestrator recommends before/with (see the session) — the owner decides.

Files most worth the owner's own eyes: `src/Unrect/SpaceCapabilities.cs`, `src/Unrect/Projections/BoundedSpace.cs`, `src/Unrect/Projections/TailSpace.cs`, `src/Unrect.Analyzers/UnrectSymbols.cs`, `src/Unrect/Projections/ProjectionBase.cs`.
